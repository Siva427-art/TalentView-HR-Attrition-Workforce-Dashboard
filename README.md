# 📊 Workforce Analytics Dashboard (Power BI) Drive Link in Last Line

## 📌 Overview

This project presents an interactive Workforce Analytics Dashboard built using Power BI. It provides insights into employee distribution, demographics, and organizational trends to support data-driven decision-making.

---

## 🎯 Objective

* Analyze workforce data across departments
* Understand employee demographics (age, gender, ethnicity)
* Track employee headcount and tenure
* Visualize key HR metrics

---

## 🛠️ Tools & Technologies

* Power BI
* Data Visualization
* DAX (Data Analysis Expressions)
* Data Modeling

---

## 📊 Dashboard Features

* 📌 Total Headcount Overview
* 📈 Average Tenure Analysis
* 📉 Employee Separations Tracking
* 👥 Gender Distribution
* 🌍 Ethnicity Distribution
* 🎯 Age Group Analysis
* 🏢 Department-wise Headcount

---

## ⚙️ Filters & Interactivity

* Mode of Work (Contract / Full-Time)
* Gender Selection
* Age Group Filter
* Department Filter
